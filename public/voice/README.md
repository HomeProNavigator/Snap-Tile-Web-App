# Celebration voice clips

Drop `.m4a` files in this folder. The app plays the matching clip when sound is on. If a file is missing, it speaks the same line with the best installed English voice.

Praise is chosen at random, and the same clip is not used twice in a row. When a builder name is set and the clip is missing, the spoken fallback is “Great job, <name>!” instead of the stock line.
